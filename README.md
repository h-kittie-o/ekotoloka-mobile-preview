# Екотолока — мобільний прев'ю

Перегляд мобільної версії сайту [Екотолока](https://h-kittie-o.github.io/ekotoloka-prototype/) у рамці iPhone — прямо на комп'ютері.

## Як подивитись

- **У браузері (онлайн):** https://h-kittie-o.github.io/ekotoloka-mobile-preview/
- **Локально:** відкрий `index.html` подвійним кліком.

## Що це

Одна сторінка (`index.html`) з CSS-мокапом айфона. Всередині — `<iframe>` шириною 390px, що вантажить **живий** сайт із основної репки
[`ekotoloka-prototype`](https://github.com/h-kittie-o/ekotoloka-prototype). Тобто будь-яка зміна основного сайту одразу видно тут — нічого синхронізувати вручну не треба.

Рамка, бічні кнопки й Dynamic Island намальовані чистим CSS, без картинок і залежностей.
